# TestEZ Runner

Lunar has a built-in TestEZ runner that runs your `*.spec.luau` tests directly inside Roblox Studio in **edit mode** — no Play needed.

To set it up, open the **Tests** panel at the bottom and click **Set up TestEZ**. Lunar will scaffold a sample spec file and configure everything automatically.

Once set up, tests run through the Studio bridge and results appear in the panel with clickable failure frames that jump to the exact line in your code.
