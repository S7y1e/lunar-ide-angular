# Keyboard Shortcuts

Lunar follows IntelliJ-style conventions. Most shortcuts can be customized in **Settings → Keybindings**.

## Search & Navigation

| Shortcut | Action |
|---|---|
| `Shift` `Shift` | **Search Everywhere** — search files, symbols, actions and text at once |
| `Ctrl+P` | Open file by name |
| `Ctrl+Shift+P` | Open command palette (actions) |
| `Ctrl+T` | Go to symbol |

> **Tip:** Inside the Search Everywhere palette, press `Tab` / `Shift+Tab` to cycle between tabs (All, Files, Symbols, Actions, Text).

## Code Navigation

| Shortcut | Action |
|---|---|
| `Alt+F7` | Find usages of the symbol under the cursor |
| `Ctrl+Alt+H` | Show call hierarchy for the function under the cursor |
| `Shift+F6` | Rename module (refactor) |
| `Alt+7` | Go to Structure panel |

## Project & Build

| Shortcut | Action |
|---|---|
| `Ctrl+Shift+B` | Build — place file via rojo |
| `Ctrl+Shift+T` | Run tests via lune |
| `Ctrl+Shift+F` | Find in Files |

## UI

| Shortcut | Action |
|---|---|
| `Ctrl+`` ` | Toggle terminal |

## Customizing Shortcuts

Go to **Settings → Keybindings** to change any shortcut. Click a binding field and press the new key combination. To remove a binding, clear the field.

All bindings are stored locally and persist across sessions.
